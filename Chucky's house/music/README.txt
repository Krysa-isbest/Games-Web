Music for Chucky's House (mp3 or ogg, ~5-10 MB per track, never over 100 MB: GitHub's limit).

1. Put the file in this folder, e.g. "main menu.mp3".
2. Add its name to the right list in list.json, e.g.  "menu": ["main menu.mp3"]

Lists: menu (main menu), intro (car radio in the opening drive), shop (radio: Chill FM),
evening (radio: Night Jazz), auction (radio: Hype Radio / auction), night (expeditions),
chase (extra layer when an enemy chases you), down (bleeding out), prison (game over).
Several files in one list = they play in random order. Empty list = silence.
The win ending track is synthesized by the game, no file needed.
